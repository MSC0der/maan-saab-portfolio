## Coding Standards

* Strict TypeScript
* No any types
* Strong typing everywhere
* Reusable components only
* No duplicated code
* No inline styles
* No hardcoded colors
* No hardcoded project content inside components

---

## Styling Standards

Use SCSS variables.

Example:

* --background
* --surface
* --primary
* --text-primary
* --text-secondary

All styling must support future theme switching.

---

## Component Standards

Components must be:

* Reusable
* Responsive
* Accessible
* Standalone

Avoid page-specific shared components.
